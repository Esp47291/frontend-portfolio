# Портфолио: фронтенд-разработка, 1 семестр

**Автор:** Даниил Алексеев
**Курс:** Skypro, «Веб-разработка», модуль «Введение в профессию, вёрстка и дизайн»

Все работы семестра в одном репозитории. Вместе они складываются в один сквозной проект: интернет-магазин мебели **«Интерьер.»**. Каждая домашка дорабатывает его на следующем шаге: сначала разметка, потом стили, БЭМ, вёрстка по макету Figma, Flexbox и Grid, SCSS, анимации и формы.

Каждая работа лежит в своей папке. Чтобы посмотреть её, откройте `index.html` из папки в браузере. Можно и с корня: [`index.html`](index.html) в корне репозитория ведёт на все проекты.

## Работы

| № | Работа | Что сделано | Технологии | Статус |
|---|--------|-------------|------------|--------|
| 01 | [Основы HTML](01-html-basics) | Семантическая разметка главной страницы и каталога: `header`, `nav`, `section`, `footer`, форма подписки | HTML | ✅ принято |
| 02 | [Основы CSS](02-css-basics) | Стилизация главной страницы: типографика, цвета, ссылки, кнопка и поле формы подписки | HTML, CSS | ✅ принято |
| 03 | [Строчные и блочные элементы](03-inline-block) | Сброс отступов, шапка фиксированной высоты, подчёркивание ссылок при наведении, отступы блоков без дублирования стилей | HTML, CSS | ✅ принято |
| 04 | [Методология БЭМ](04-bem) | Все классы проекта переименованы по БЭМ, нет селекторов по id и тегам | HTML, CSS, БЭМ | ✅ принято |
| 05 | [Работа с макетом Figma](05-figma-layout) | Вёрстка по макету Figma: стартовый блок, шапка, «Специальные предложения», подключение шрифта Montserrat, структура `img/` и `fonts/` | HTML, CSS, Figma | ✅ принято |
| 06 | [Позиционирование Flexbox](06-flexbox) | Выравнивание шапки, карточек товаров и подвала через Flexbox, общий класс для центрирования | HTML, CSS Flexbox | ✅ принято |
| 07 | [Позиционирование Grid Layout](07-grid) | Блок «Мебель для…» на CSS Grid по макету, отдельная страница каталога со своими стилями | HTML, CSS Grid | ✅ принято |
| 08 | [Препроцессоры CSS](08-scss) | Перевод стилей на SCSS, партиал `_cart.scss`, новая страница «Корзина», компиляция в CSS с source map | HTML, SCSS | ✅ принято |
| 09 | [Декоративные элементы и анимация](09-decor-animation) | Состояния `:hover`, `@keyframes`-анимации, псевдоклассы | HTML, CSS-анимации | ✅ принято |
| 10 | [Работа с формами](10-filter-form) | Блок фильтрации каталога: кастомные радиокнопки и чекбоксы, цветные чекбоксы, двойной ползунок цены, адаптив под десктоп, планшет и мобильные | HTML, CSS, JavaScript | 🕓 на проверке |

## Навыки

- Семантическая вёрстка на HTML5, формы и их элементы
- CSS: каскад, селекторы, блочная модель, Flexbox, Grid, позиционирование
- Методология БЭМ
- Вёрстка по макету из Figma
- Препроцессор SCSS: переменные, вложенность, партиалы
- Анимации и переходы, псевдоклассы и псевдоэлементы
- Кастомизация элементов форм, адаптивная вёрстка через медиазапросы
- Немного JavaScript для интерактивных элементов
