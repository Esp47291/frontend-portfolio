# Портфолио: фронтенд-разработка, 1 семестр

**Автор:** Даниил Алексеев
**Курс:** Skypro, «Веб-разработка», модуль «Введение в профессию, вёрстка и дизайн»

**🌐 Живая версия портфолио: https://esp47291.github.io/frontend-portfolio/**

Все работы семестра в одном репозитории. Вместе они складываются в один сквозной проект: интернет-магазин мебели **«Интерьер.»**. Каждая домашка дорабатывает его на следующем шаге: сначала разметка, потом стили, БЭМ, вёрстка по макету Figma, Flexbox и Grid, SCSS, анимации и формы.

У каждой работы есть живая ссылка: страница открывается прямо в браузере, ничего не нужно скачивать. Исходники лежат в одноимённой папке.

## Проект семестра: Ratify

**Репозиторий:** https://github.com/Esp47291/ratify

Сайт маркетингового агентства: Яндекс.Директ, SEO-продвижение, аудит сайта, ведение карточки компании в Яндекс.Бизнесе. Посетитель выбирает услугу, считает бюджет в калькуляторе и оставляет заявку. Заявка сохраняется в базу данных и приходит в Telegram.

- **Стек:** Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4, Framer Motion, PostgreSQL 16, Drizzle ORM
- **Что внутри:** 13 страниц, единый шаблон страниц услуг из одного источника данных, калькулятор бюджета, API приёма заявок с валидацией, проверка работоспособности `/api/health`, SEO (`sitemap.xml`, `robots.txt`)
- **Инфраструктура:** Docker Compose (сайт + PostgreSQL), скрипты деплоя на VPS
